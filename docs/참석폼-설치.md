# 참석 폼 → 구글 시트 연결 설치 안내

초대장 하단의 「참석 알려주기」 폼이 구글 시트로 바로 쌓이게 하는 설정입니다.
**전부 사용자 구글 계정에서 직접 하셔야 합니다** (계정 접근 권한이 필요한 작업이라 대신 해드릴 수 없습니다).

소요 시간 약 5분.

---

## 1단계 — 구글 시트 만들기

1. [sheets.new](https://sheets.new) 접속 (재단 계정 `mcancer.maria@gmail.com`으로 로그인된 상태에서)
2. 시트 이름을 `가브리엘라 축복미사 참석명단` 정도로 지정

## 2단계 — Apps Script 붙여넣기

1. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**
2. 편집기에 있던 기본 코드(`function myFunction() {}`)를 **전부 지우고**
3. `docs/google-apps-script.gs` 내용을 **통째로 복사해 붙여넣기**
4. 저장 (⌘S)

## 3단계 — 웹 앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 좌측 톱니바퀴(유형 선택) → **웹 앱**
3. 설정:

   | 항목 | 값 |
   |---|---|
   | 설명 | `참석 접수` (아무거나) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ← 반드시 이걸로 |

4. **배포** 클릭
5. 권한 승인 창이 뜹니다:
   - **액세스 승인** → 재단 계정 선택
   - "Google에서 확인하지 않은 앱입니다" 경고가 나오면
     → **고급** → **○○○(안전하지 않음)으로 이동** → **허용**
   - (본인이 만든 스크립트라 정상입니다)
6. 배포 완료 후 나오는 **웹 앱 URL을 복사**

   생김새: `https://script.google.com/macros/s/AKfycb.....................정말김/exec`

## 4단계 — URL 전달

복사한 URL을 그대로 알려주세요. 초대장에 연결하고 배포하겠습니다.

> ⚠️ **"액세스 권한이 있는 사용자"를 "모든 사용자"로 하지 않으면** 초대장에서 보낸 참석 정보가 저장되지 않습니다. 가장 흔한 실수입니다.

---

## 배포가 잘 됐는지 혼자 확인하는 법

복사한 웹 앱 URL을 브라우저 주소창에 그대로 붙여넣고 열어보세요.

```json
{"ok":true,"message":"참석 접수 준비됨","count":0}
```

이렇게 뜨면 정상입니다. 로그인 화면이나 오류가 뜨면 3단계 설정을 다시 확인해 주세요.

---

## 시트에 쌓이는 형태

| 접수시각 | 소속 | 이름 | 연락처 | 동행인 | 총인원 |
|---|---|---|---|---|---|
| 2026-08-11 14:23:07 | 마뗄암재단 후원회 | 홍길동 | 010-1234-5678 | 2 | 3 |

- **총인원** = 본인 1명 + 동행인. 이 열을 합계 내면 전체 참석 인원이 나옵니다
- 7번째 열(접수키)은 중복 저장을 막기 위한 내부용이라 자동으로 숨겨집니다

---

## 알아두실 것

**중복 저장 차단** — 참석자가 버튼을 여러 번 눌러도 같은 접수키는 한 번만 저장됩니다.

**봇 차단** — 사람 눈에 안 보이는 함정 필드를 두어 자동 등록 프로그램을 걸러냅니다.

**전송 실패를 화면에서 알 수 없습니다** — 구글 Apps Script는 브라우저가 응답을 읽을 수 있게 해주는 헤더(CORS)를 붙이지 못합니다. 그래서 초대장은 요청을 보낸 뒤 성공했다고 가정하고 완료 화면을 띄웁니다.
→ **연결 직후 반드시 테스트 접수를 한 번 넣어보고 시트에 줄이 생기는지 확인**해 주세요. 한 번 확인되면 그 뒤로는 안정적으로 동작합니다.

**개인정보** — 이름·연락처를 받으므로 초대장에 "행사 준비와 참석 확인에만 사용하며 행사 종료 후 파기합니다" 문구를 넣어 두었습니다. 행사가 끝나면 시트를 정리해 주세요.

**수정이 필요하면** — Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.
