# 오프라인 초대장 (A4 단면)

## 파일

| 파일 | 용도 |
|---|---|
| `가브리엘라_축복미사_초대장_A4.pptx` | **다른 사람이 텍스트 고칠 때** — 파워포인트로 열어서 바로 수정 |

## 규격
- A4 세로 210×297mm, **1페이지 단면**, 흰 배경, 컬러
- 여백: 좌우 20mm / 상하 12mm — 가정용 프린터 여백 안에 들어감
- 배경이 종이 끝까지 닿지 않으므로 **재단여백(bleed) 불필요**

## 글꼴 — 나눔명조 · 나눔고딕

두 가지만 씁니다. **없으면 파워포인트가 다른 글꼴로 바꿔버려 모양이 달라집니다.**
무료이니 편집하실 분 PC에 먼저 설치해 주세요.

- 나눔명조 — 표제, 본문, 식순
- 나눔고딕 — 머리말, 라벨(식 순 / 준비해 주세요 / 오시는 길), 영문 꼬리말

내려받기: https://hangeul.naver.com/font

## PPTX 편집 요령

- 모든 문구가 **개별 텍스트 상자**입니다. 고칠 곳을 두 번 눌러 바로 입력
- 글자를 크게 늘리면 아래 요소와 겹칠 수 있으니, 늘린 뒤 겹치는지 확인
- 색: 본문 `1C2A25` / 보조 `57665F` / 강조 초록 `157A63` / 선 `DDD5C4`
- 편집 후 인쇄: 파일 → 내보내기 → PDF, **용지 A4 세로** 확인

## 인쇄 설정
- 용지 A4
- 배율 **100% / 실제 크기** (「페이지에 맞춤」 끄기 — 켜면 축소됨)
- 컬러·흑백 어느 쪽이든 무방

## 재생성

PDF (HTML 수정 후):
```
cd print
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-pdf-header-footer --virtual-time-budget=12000 \
  --print-to-pdf="가브리엘라_축복미사_초대장_A4.pdf" "file://$PWD/초대장_A4단면.html"
```

PPTX (make_pptx.py 수정 후):
```
cd print && python3 make_pptx.py
```
